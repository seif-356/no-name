# No-name: AI company brain for small Egyptian businesses

A done-for-you service that cleans and organizes a small company's messy data (files, Excel, WhatsApp, scans, Arabic documents) and connects an AI that answers from it, over web chat and WhatsApp, optionally hosted locally in Egypt.
